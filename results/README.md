# Evaluation outputs

These files were generated by running `python evaluate.py` from the repository root.

- `cross_validation.csv`: training-only five-fold model comparison.
- `holdout_metrics.json`: selected-model holdout scores and confusion counts.
- `run_metadata.json`: seed, dataset hash, versions and verification checks.
- `confusion_matrix.png`: holdout prediction summary.

See the root README for methodology and limitations.
